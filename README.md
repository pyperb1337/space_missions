# Каталог космических миссий

Консольное приложение для просмотра и поиска космических миссий по направлению.

## Возможности
* Вывод полного списка миссий
* Поиск миссий по направлению

## Структура проекта
| Файл | Описание |
| --- | --- |
| `main.py` | Главный файл запуска |
| `missions.py` | Логика отображения и поиска миссий |
| `README.md` | Документация проекта |

## Запуск
```bash
python main.py
